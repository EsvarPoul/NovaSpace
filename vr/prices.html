Pricing

Прозора система пакетів для різних форматів гри.

Тестові цінові пакети оформлені як база для подальшого наповнення реальними тарифами, сезонними пропозиціями та сценаріями подій.

Гнучкоціни легко масштабуються під групові формати та спеціальні події
Тарифи

Три базові формати для старту.

Solo / Duo

Private Session

Індивідуальна або парна сесія з м’яким супроводом і рекомендованими іграми.

900 грн / 60 хв
  • 1-2 гравці
  • Інструктаж перед стартом
  • Підбір гри під рівень досвіду
Friends

Group Play

Сценарій для компанії друзів з активними або кооперативними іграми.

1500 грн / 60 хв
  • 3-6 гравців
  • Ротація команд за потреби
  • Допомога адміністратора
Celebration

Event Format

Розширений формат для дня народження чи міні-корпоративу.

від 2800 грн / пакет
  • Гнучка тривалість
  • Сценарій під подію
  • Окремий супровід групи
Що входить

У кожен тариф входить базовий сервіс.

  • Підготовка обладнання до сеансу
  • Інструктаж і допомога з вибором сценарію
  • Супровід під час гри за потреби
Примітки

Що важливо уточнити перед бронюванням.

  • Ціни вказані як тестові дані-заглушки
  • Для великих подій пакет прораховується окремо
  • Святкові дні можуть мати окремий прайс
